# Python Automation

Small, practical scripts that automate the repetitive parts of lab work.
Each script is standalone — read the docstring at the top before running it.

## Scripts

| Script | What it does |
|--------|--------------|
| `subnet_calc.py` | Subnet calculator: given an address and prefix, prints network, broadcast, usable range, and wildcard mask. Built to drill the subnetting speed the CCNA demands. |

## Ground rules

- Standard library only unless a script's docstring says otherwise.
- Every script prints its own usage when run without arguments.
- Nothing here touches real equipment — lab and study use only.
